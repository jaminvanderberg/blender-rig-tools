    Workflow

    1. Create the initial rig skeleton:

      Add > Armature > RigTools Human Skeleton
      Use this base skeleton, customize it, and fit it to your character, or create the skeleton manually.

    2. [Optional] Add twist bones

      n-Panel > RigTools > Tools > Add Twist Bones Create twist bones on the arm, legs, chest, and neck as desired. These can also be created manually. See twist bones for more information.

    3. Weight paint the character

      Weight paint the character as you normally would. This can be done manually or with standard Blender tools. The weight paint proxy tool might help in some niche cases.

    4. Create the ORG bones

      n-Panel > RigTools > Tools > Generate ORG Bones See Generate ORG Bones for more details. This tool duplicates every DEF bone and creates a Copy Transforms constraint from the ORG bone to the DEF bone.

    5. Create the Torso assembly

      n-Panel > RigTools > Forward Kinematics > Torso Select the torso bones, neck, and head (excluding twist bones) and create the torso assembly. See torso assembly

    6. Create the Arm and Leg assemblies

      n-Panel > RigTools > Inverse Kinematics > Arm and Leg See ik_assemblies for more information

    7. Create additional assemblies as desired.

      Add shoulder, palm, and finger assemblies if desired. Add assemblies for hair, cloth, tails, etc. Use "FK only" for short detail chains, or "Simple FK" if you want tweak controls.
