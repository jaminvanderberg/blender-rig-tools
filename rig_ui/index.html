    Rig UI

    Info

    This is AI-generated documentation that has not yet been human reviewed.

    After the assemblies are built, animators work from the Rig UI panels in the Item tab of the n-panel, not the RigTools build panels. The Rig UI is built into the addon. These is currently no script to generate, but this is a planned development for the future.

    Tip

    Bone collections created by assemblies are kept when you delete or reconfigure an assembly, so your Rig UI layout survives rebuilds. See Assemblies.

    Panels

    With the armature selected (or a mesh deformed by the armature):

    Panel Tab Purpose
    Rig UI Item Buttons to show and hide bone collections
    Rig Properties Item FK/IK switching, IK parents, rotation follow, and other assembly properties, plus FK <> IK snapping
    Visibility Item Show and hide the character's meshes and mask modifiers

    Image placeholder

    image/rig_ui_overview.png — The Item tab with all three panels open (Rig UI, Rig Properties, Visibility) while an arm control is selected.

    Note

    The Rig UI panels are part of the RigTools addon. Animators need RigTools installed to see them.

    Typical animator workflow

    1. Set up the Rig UI layout once: arrange the buttons, and hide the collections animators don't need (like MCH and ORG).
    2. Select a control. The Rig Properties panel shows the properties for that limb.
    3. Switch between FK and IK with the FK/IK buttons, using the snap buttons to keep the pose.
    4. Use the Visibility panel to hide clothing or meshes that are in the way.
